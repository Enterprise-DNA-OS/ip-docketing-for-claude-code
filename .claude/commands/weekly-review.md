---
description: The Monday docket meeting: deadlines, renewals, workload and compliance, written up.
---

Run `npm run docket -- weekly-review --json`.

Write a one-page note for the Monday docket meeting:
1. **Missed or due in 14 days:** each statutory date, the case, the attorney, checked or not.
2. **Renewals:** lapsed, in grace, awaiting instructions, instructed but not paid.
3. **Workload:** overdue, this week and unchecked by attorney. Flag anyone carrying more than five dates this week.
4. **Compliance:** the count by rule, and the three to fix first.

End with three actions for this week, each naming a person. Save it to `drafts/weekly-review-<date>.md`.
