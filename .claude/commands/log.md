---
description: A case note: a call, email, meeting or note.
---

Run `npm run docket -- log --case=<ref> --note="<what happened>" --kind=call|email|meeting|note --actor="<operator>"`.

Write the note in the operator's words, plain and dated by the system. If the note contains an instruction or a date, offer the matching command (`/instruct`, `/add-deadline`).
